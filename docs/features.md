# 機能要件詳細

## 1. 業務フロー

### 1-1. 収支登録

```
収支一覧 → [新規登録]ボタン
    ↓
モーダル表示
  区分（収入 / 支出）を選択
  金額・日付・カテゴリ・サブカテゴリ・メモ を入力
    ↓
[保存]
  → DBに登録 → 収支一覧へ反映
```

### 1-2. 収支編集・削除

```
収支一覧で対象行の [✏️] をクリック
    ↓
同一モーダルに既存データが読み込まれる
  修正して [保存] → 更新
  [削除] をクリック → 確認なしで即削除
```

### 1-3. 予算チェック

```
予算設定ページで月を選択 → 予算額を入力 → [保存]
    ↓
ダッシュボード・予算設定ページで
  支出合計 / 予算額 の進捗バーを表示
  超過時はアラートバナー（⚠️）を表示
```

## 3. 機能要件詳細

### 3-1. 収支登録

| 項目 | 仕様 |
|------|------|
| 区分 | 収入 / 支出 の 2 択（ラジオ的なトグルボタン） |
| 金額 | 必須・正の整数（円） |
| 日付 | 必須・YYYY-MM-DD 形式 |
| カテゴリ | 必須・ユーザーが登録したカテゴリから選択 |
| サブカテゴリ | 任意・選択したカテゴリに紐付くサブカテゴリから選択 |
| メモ | 任意・100文字以内 |

**バリデーション:** 金額が空または 0 以下の場合はエラーメッセージを表示してサブミットを阻止する。

### 3-2. カテゴリ管理

**デフォルトカテゴリ（支出）**

| カテゴリ | 代表サブカテゴリ |
|---------|--------------|
| 食費 | 食料品・外食・カフェ・飲み物・お酒 |
| 日用品 | 洗剤・掃除用品・キッチン用品 |
| 娯楽費 | 映画・音楽・ゲーム・旅行・本・趣味 |
| 交通費 | 電車・バス・タクシー・飛行機 |
| 衣類・美容 | 服・クリーニング・理髪・美容・化粧品 |
| 医療・健康 | 医療費・薬・フィットネス |
| 自動車費 | ローン・ガソリン・有料道路・駐車場・保険・車検 |
| 教育・自己投資 | IT機器・書籍・学費・塾・習い事 |
| 水道・光熱費 | 水道・電気・ガス |
| 住居費 | 住宅ローン・家賃・管理費・保険 |
| 保険 | 生命保険・医療保険 |
| 交際費 | 飲み会・冠婚葬祭・贈り物 |
| 通信費 | スマホ・インターネット・NHK |
| 税・その他 | ふるさと納税 |

**デフォルトカテゴリ（収入）**

| カテゴリ | 代表サブカテゴリ |
|---------|--------------|
| 収入 | 給与・ボーナス・投資利益・配当金 |

**カテゴリ追加仕様:**
- ユーザーが名前・カラー（カラーピッカー）・区分（収入/支出）を入力して追加できる。
- カテゴリ名は最大 20 文字。
- デフォルトカテゴリは削除不可。ユーザー追加カテゴリのみ削除可。

**サブカテゴリ仕様:**
- カテゴリに属するサブカテゴリのリスト。
- テキスト入力で追加・×ボタンで削除。
- 同名サブカテゴリの重複登録は不可。
### 3-3. 収支一覧フィルタ

| フィルタ項目 | 選択肢 |
|------------|-------|
| 区分 | すべて / 収入のみ / 支出のみ |
| カテゴリ | すべて / 各カテゴリ |
| サブカテゴリ | すべて / 選択カテゴリのサブカテゴリ |
| 集計期間 | 月別 / 週別 / 年別 |
| 年 | 年セレクター |
| 月 | 月セレクター（月別・週別のみ表示） |
| 週 | 第1週〜第5週（週別のみ表示） |

- フィルタは選択即時反映（サブミット不要）。
- 「リセット」ボタンで全フィルタをデフォルトに戻す。
- フィルタ結果の収入合計・支出合計・残高をフィルタバーの下に表示する。

**週の定義:**
- 第1週: 1〜7日
- 第2週: 8〜14日
- 第3週: 15〜21日
- 第4週: 22〜28日
- 第5週: 29日以降

### 3-4. ダッシュボード

- 表示期間: 今月 / 今週 / 今年 / 月選択 / 年選択 から選択。
- 収入合計・支出合計・残高（収入 − 支出）をサマリーカードで表示。
- 支出合計が月間予算を超えた場合にアラートバナー（⚠️）を表示。
- カテゴリ別内訳テーブル（収入カテゴリ・支出カテゴリ別に金額・割合を表示）。

### 3-5. 予算管理

- 月ごとに総予算を設定する（カテゴリ別予算は対象外）。
- 年を選択し、全12ヶ月の予算・実績支出・差額・達成率を一覧テーブルで表示。
- 達成率が100%を超えた月は進捗バーを赤色で表示。
- 予算超過アラートはダッシュボード画面に表示（予算設定画面では進捗バーの色で判断）。
- 画面下部に年間サマリー（年間収入合計 − 予算合計 ＝ 貯金見込み額）を表示。

### 3-6. グラフ・レポート

| 項目 | 仕様 |
|------|------|
| 表示期間タイプ | 月別 / 年別 |
| 表示種別 | 支出のみ / 収入のみ |
| 月別: カテゴリ別ドーナツグラフ | 選択カテゴリのカテゴリ別内訳・割合表示 |
| 月別: 日別棒グラフ | 日ごとの金額推移（日別 / 週別切替あり） |
| 年別: カテゴリ別ドーナツグラフ | 年間のカテゴリ別内訳 |
| 年別: 月別棒グラフ | 月ごとの金額推移 |

### 3-7. CSVエクスポート

- グラフ・レポートページで選択中の年月・区分（収入/支出）・期間タイプでフィルタしたデータをエクスポートする。
- ファイル名: `budgeting_{年}-{月}.csv`（年別の場合は `budgeting_{年}.csv`）。
- 文字コード: UTF-8（BOM付き）。
- カラム: 日付, 区分, カテゴリ, サブカテゴリ, メモ, 金額。
