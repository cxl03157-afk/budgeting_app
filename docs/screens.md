
## 5. レスポンシブ対応

| ブレークポイント | レイアウト |
|--------------|---------|
| ≥ 768px（PC） | サイドバー固定表示 + メインコンテンツ横並び |
| < 768px（スマホ） | サイドバーをハンバーガーメニュー化（最終版で対応） |

プロトタイプはPCブラウザ（`file://`直接起動）を対象とし、スマートフォン対応は最終版（Vue.js + Vuetify）で実装する。
