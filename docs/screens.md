┌────────────┐ ┌────────────┐ ┌────────────┐
│  収入合計  │ │  支出合計  │ │    残高    │
│  ¥xxx,xxx  │ │  ¥xxx,xxx  │ │  ¥xxx,xxx  │
└────────────┘ └────────────┘ └────────────┘

┌────────────────────────────────────────────┐
│ カテゴリ別内訳                              │
│ 区分 | カテゴリ | 金額       | 割合        │
│ 支出 | 食費    | ¥xx,xxx   | xx%         │

```

│ ...                                                  │
└──────────────────────────────────────────────────────┘
```

### SCR-03: 収支登録・編集モーダル

```
┌─────────────────────────────┐
│ 収支を登録          [✕]     │
├─────────────────────────────┤
│ 区分    [支出] [収入]        │
│ 金額  ¥ [________]  ※必須  │
│ 日付    [________]  ※必須  │
│ カテゴリ [▼________]        │
│ サブカテ [▼________]        │
│ メモ    [________________]  │
├─────────────────────────────┤
│ [削除]  [キャンセル] [保存]  │
└─────────────────────────────┘
```

- 削除ボタンは編集時のみ表示。
- 金額が空の場合、エラーメッセージを金額フィールド下に表示。

### SCR-04: カテゴリ管理

```
[カテゴリ管理]

┌─────────────────────────────┐
│ カテゴリを追加               │
│ [名前____] [🎨] [区分▼] [追加] │
└─────────────────────────────┘

┌────────── 支出カテゴリ ──────────┐
│ ● 食費        [+サブカテゴリ追加] │
│   食料品 [×]  外食 [×]  ...     │
│ ● 日用品  ...                   │
│ ...                             │
└──────────────────────────────────┘

┌────────── 収入カテゴリ ──────────┐
│ ● 収入        [+サブカテゴリ追加] │
│   給与 [×]  ボーナス [×]  ...   │
└──────────────────────────────────┘
```

- デフォルトカテゴリに削除ボタンは表示しない。
- ユーザー追加カテゴリには削除ボタン（🗑️）を表示。

### SCR-05: 予算設定

```
[予算設定]

[2026年▼]

┌────────────────────────────────────────────────────────┐
│ 月 | 予算       | 実績       | 差額       | 達成率      │
│ 1月 | ¥xxx,xxx | ¥xxx,xxx  | ¥xxx,xxx  | xx%        │
│ 2月 | ¥xxx,xxx | ¥xxx,xxx  | ¥xxx,xxx  | xx%        │
│ ...                                                    │
│ 12月| ¥xxx,xxx | ¥xxx,xxx  | ¥xxx,xxx  | xx%        │
└────────────────────────────────────────────────────────┘

┌────────────────────────────────┐
│ 年間貯金見込み額                 │
│ 年間収入 − 年間予算 = ¥xxx,xxx  │
└────────────────────────────────┘
```

- 年セレクターで表示年を切替。全12ヶ月の予算・実績・差額・達成率を一覧表示。
- 予算未設定の月は予算・差額・達成率を空欄で表示。各行クリックで予算を編集。

### SCR-06: グラフ・レポート

```
[グラフ・レポート]   [月別▼] [支出のみ▼] [年▼] [月▼]  [📥 CSVエクスポート]

┌──────────────────────┐  ┌──────────────────────────────┐
│ カテゴリ別内訳         │  │ 推移        [日別] [週別]     │
│                      │  │                              │
│   （ドーナツグラフ）   │  │      （棒グラフ）              │
│                      │  │                              │
└──────────────────────┘  └──────────────────────────────┘
```

- 年別選択時: 月セレクター・日別/週別切替を非表示にする。
- 年・月が未選択の場合はグラフを空で表示する。
