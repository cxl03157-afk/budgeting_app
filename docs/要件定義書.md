# 要件定義書

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | 家計簿アプリ（Budgeting App） |
| 目的 | 収支の記録・集計・可視化を通じて家計管理を支援する |
| 対象ユーザー | 自分のみ（シングルユーザー） |
| 作成日 | 2026-05-08 |

---

## 2. 背景・課題

日々の収支を手軽に記録・可視化することで、家計の把握と改善を支援するアプリを作成する。  
以下の技術要素を実践的に習得することが学習目標である。

- Vue.js 3 によるコンポーネント設計とリアクティブUI
- Python + FastAPI による REST API 設計・実装
- SQLAlchemy を用いたデータアクセス層の実装と SQL 集計処理の理解
- MySQL によるリレーショナルデータ管理
- AWS（S3 / EC2 / RDS）へのフルスタックデプロイ

---

## 3. 機能要件

詳細な仕様・ユースケースは [features.md](./features.md) を参照。

### 3-1. 収支管理
- 収支の新規登録（金額・日付・カテゴリ・メモ・収入/支出区分）
- 収支の編集
- 収支の削除

### 3-2. カテゴリ管理
- デフォルトカテゴリ（食費・日用品・交通費・通信費・住居費・光熱費・娯楽費・医療費・教育費・収入・その他）
- カテゴリの追加・削除
- 登録済み収支のカテゴリ変更
- カテゴリ内にサブカテゴリを設定できる（詳細は features.md）

### 3-3. 集計・フィルタリング
- 月別 / 週別 / 年別 集計
- 日付範囲・カテゴリによるフィルタリング

### 3-4. グラフ表示
- 表示切替：収入のみ / 支出のみ を選択できる
- カテゴリ別円グラフ（内訳）
- 日付別棒グラフ（推移）

### 3-5. 予算管理・貯金試算
- 月間の総予算を設定する（全体予算）
- 「可能な貯金額 ＝ 収入合計 − 総予算」を画面上に表示する
- 支出合計が総予算を超えた場合にアラート表示する

### 3-6. その他
- CSVエクスポート（フィルタ後データをダウンロード）
- ダークモード切替

---

## 4. 非機能要件

### 4-1. データ保存・認証・動作環境

| 項目 | 内容 |
|---|---|
| データ保存 | MySQLに保存する。フロントエンドはREST APIを通じてバックエンドと通信する |
| 認証 | 不要（ログイン機能なし・シングルユーザー前提） |
| 対応環境 | PCブラウザ（Chrome・Safari） |
| レスポンシブ | PCブラウザ向けのみ対応（スマートフォン最適化は対象外） |

**受け入れ基準**
- [ ] ページをリロード・再起動しても収支データが保持されている
- [ ] 登録・編集・削除が即時DBに反映される

---

### 4-2. セキュリティ要件

| 項目 | 方針 |
|---|---|
| XSS対策 | ユーザー入力をそのままDOMに埋め込まない（Vueのテンプレートエスケープを利用する） |
| CORS | バックエンドはフロントエンドのオリジンのみ許可する |
| SQLインジェクション対策 | SQLAlchemy のパラメータバインドを使用し、生SQLは原則使用しない |
| 外部通信 | フロントエンドは自前バックエンドのAPIのみと通信する |
| 依存パッケージ | 必要最小限かつメンテ継続中の著名なパッケージを使用する |

**受け入れ基準**
- [ ] メモ欄にHTMLタグを入力しても文字列として表示される（タグとして実行されない）
- [ ] フロントエンド以外のオリジンからのAPIリクエストが拒否される

## 5. 技術スタック

| レイヤー | 技術 |
|---|---|
| フロントエンド | Vue.js 3 + TypeScript + Vuetify |
| バックエンド | Python + FastAPI + SQLAlchemy |
| データベース | MySQL |
| AWSデプロイ | S3+CloudFront（フロント）/ EC2 t2.micro（バック）/ RDS db.t3.micro MySQL（DB）|

※ AWS無料枠（12ヶ月）の範囲内で運用可能

詳細な選定理由は [tech-stack.md](./tech-stack.md) を参照。

---

## 6. スコープ外

- ユーザー認証・複数ユーザー対応
- 銀行口座・外部サービスとのAPI連携
- レシートOCR読み取り
- プッシュ通知・メール通知
- 複数通貨対応
- 繰り返し取引の自動生成（DBカラムは残存）
- グラフの収支合計表示（支出のみ / 収入のみ のみ対応）
- スマートフォン向けレスポンシブ最適化
